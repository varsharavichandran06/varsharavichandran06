# Hi, I'm Varsha 👋

GenAI Engineer building multi-agent and RAG systems. MS in Computer Science at UMass Amherst (May 2026). Previously interned at Microsoft and IBM.

## What I'm working on

- 🤖 **AgentOS** — an ambient multi-agent system that protects your health and time during a job search. It syncs your calendar, defends focus blocks and meals from getting bumped by interviews, triages your inbox, and uses Gemini to reason about where a moved task should go instead of relying on a fixed heuristic. Built with a custom ADK-style runtime, AES-256-GCM encryption at rest, Firestore-backed sessions, and a CI/CD pipeline that deploys straight to Cloud Run.
- 🔍 **GHLens** — an agent that lets you query any GitHub repo in plain English. Built with Streamlit, MCP, and Agno, it pulls live repo and PR data and has an LLM summarize it.
- ☁️ Learning Google Cloud's Agent Development Kit and Vertex AI pipelines, and building multi-agent pipelines with them

## Background

- Software Engineering Intern at Microsoft: built a self-correcting DevOps agent for Azure Resource Provider code generation. Cut authoring time from about 4 weeks to about 10 minutes using a metadata-driven RAG approach and an automated build-fix-rebuild loop.
- Software Developer at IBM: built RAG chatbot platforms with Django and Milvus, cut manual search effort by 60%, and merged 3 separate chatbots into one interface.
- Graduate Research Extern at AWS: exploring how multi-agent RL primitives can be built into LLM training so models learn strategic reasoning during training.
- Graduate Student Researcher (with Cisco): built the subquery decomposition and verification modules for a multi-document QA system, improving F1 by 20% over a DRAGIN Vicuna-13B baseline.
